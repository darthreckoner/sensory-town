# STATE

## Build version
v1 — first complete playable build (in progress; see SCORECARD.md for grades).

## What the player should feel (this build)
1. "This town is ours, and my stuff in it is mine" — my look, my car, my houses, my squishies.
2. Every squeeze, crack, snap and steer answers instantly with a crisp, satisfying sound + visual.
3. Nothing to lose, nothing to win — just making things and playing with them.

## What exists
- App shell: scene manager (fade transitions, rAF watchdog), typed event bus, juice layer (procedural Web Audio synth + particles), tuning file, IndexedDB save store with versioned schema + migration hook, `navigator.storage.persist()`, PWA (manifest, icons generated by `scripts/make-icons.mjs`, Workbox service worker precaching everything), debug overlay + F1/F2/F3, three-finger tap.
- Profile picker (pedestals, rename, add player, audio unlock on first tap).
- Global 🏠 menu: Drive / Build / Workshop / Dress Up, Switch Player, Sound settings, Share Town (Web Share API with file → download fallback), Get Town (file picker + confirm → replace).
- Workshop scene (cozy craft room, shelf showing the player's saved creations) with three stations:
  - Squishy: 5 shapes with kawaii faces (bun, cat, star, peach, cube), 16 colors, multi-touch dents with gaussian falloff + volume ring, whole-body squash, slow memory-foam rise, recovery pop, Keep it!
  - Wax: Pick → Coat (dip into the pot by dragging the squishy down; pour by carrying the jug over it — tilts around its spout; layers have per-vertex coverage with drippy edges; wet → matte hardening; ❄️ Cool) → Crack (Voronoi pre-fractured shell, hairline cracks radiate from the exact press point, stress → crack gap → peel on a hinge → fall with gravity onto the plate; broken edges show the colored layer stripes; squishy bulges through openings; chain reaction; auto-clear + confetti). 🔁 Again / ✨ New / 💾 Keep.
  - Slime: (Sonnet coder — see report).
- Dress-up, Drive (town, car, jobs), Build (houses, village) — built by Sonnet coders against the shared contracts in `docs/CODER_BRIEF.md`.

## Assumptions made (Director's calls, need designer review)
- "Build together" = both profiles build in one shared town on the same iPad; the two iPads swap towns via export/import files. No live sync (offline, no server).
- Import replaces the entire town **and** all profiles on the receiving iPad (simplest mental model: "now both iPads have the same town"). This iPad's sound settings are kept.
- After picking a profile the game opens Dress Up first (matches the session loop: dress → drive → build/workshop); "Let's go!" drives off.
- Car color is chosen from a 🎨 button in the Drive scene (it's where the car is).
- Wax coating happens with the squishy hanging from a candy stick over the pot (dip = drag it down); cracking happens on a plate.
- Wax hardens automatically after each layer (`tuning.wax.hardenTime` = 4 s); ❄️ Cool speeds it up 4×. Cracking is blocked (with a hint) until every layer is hard.
- Hosting: GitHub Pages via Actions (`.github/workflows/deploy.yml`), `BASE=/<repo>/`.
- Fonts: system rounded font (`ui-rounded` = SF Pro Rounded on iPad) — no web fonts, fully offline.
